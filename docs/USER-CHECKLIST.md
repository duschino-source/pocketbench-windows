# Your submission checklist

Engineering setup, repository creation, API integration, builds, automated checks, repair coverage documentation, and the demo script are handled in this repository.

- Confirm you are an approved participant, meet eligibility requirements, and have accepted the event terms. Every human collaborator must also be approved.
- Confirm your entry track. The default proposal is Indie Developer, with Push the Frontier as the problem statement.
- Check billing and credits in your Meta account. The development budget remains $90; provider billing alerts are not assumed to stop spending.
- Respond yourself to any required account authentication or Windows UAC prompt. The app explains affected resources before applying a fix.
- Record the three-minute demo using docs/DEMO.md. Show genuine before/after checks and only features built during the event.
- Upload the video somewhere judges can access without requesting permission.
- Submit the public repository, video link, and every approved human team member by November 4, 2026, 6 PM Pacific / 9 PM Eastern.

Submission: https://cerebralvalley.ai/e/meta-ai-developer-hackathon/hackathon/submit

The public source never includes an API key. Anyone running the distributed app supplies their own Meta Model API credential in Settings.
