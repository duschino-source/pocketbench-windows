# Builder introduction

Hey everyone! 👋 I’m building **PocketBench**, a Windows desktop app that uses Meta’s Muse models to investigate and repair problems with Windows and installed apps.

It researches official documentation and community reports, prepares a repair you can review, then applies supported fixes with one button and checks the result. Windows is the main focus—network issues, services, startup, and system integrity—with deeper support for Firefox, Steam, and Obsidian.

My goal is to help people get from “something’s broken” to a working computer, with a clear record of what changed and undo where supported.

Looking forward to connecting with others building practical AI agents and desktop tools!
