# Event contributions

Custom implementation started October 30, 2026. This standalone repository contains work created during the event. Dependencies retain their own licenses.

- Human product direction: duschino-source.
- Engineering orchestration, integration, and verification: Codex.
- Delegated implementation: Meta Muse Spark 1.3 via OpenCode and a metered local gateway.

Custom event work includes the Electron security boundary and React/Fluent UI, Windows/app inventory, packaged native Windows operations, app-specific config/cache repairs, source assessment and structured model orchestration, budget gateway, independent verification and guarded undo, automated tests, installer packaging, and demo preparation tools.

Muse Spark coding tasks ran through OpenCode using the local budget gateway, with at most two workers concurrently. Codex reviewed and integrated their output, corrected unsafe or unsupported behavior, and implemented additional Windows/app handling and verification. AI tools are identified here as tools; they are not human team members.

The repository history records the event implementation. [Verification results](docs/VERIFICATION.md) distinguish disposable real Windows tests, isolated app-profile tests, live Meta research, and read-only host checks. Dependency source, Windows utilities, and external documentation are third-party work and are not presented as custom event contributions. The current brand concept was generated with Muse Image and finished as vector artwork during the event; [brand provenance](docs/BRAND.md) records the model prompt and contributions.

The desktop UI was refined during the event with a repair composer, a persistent app inspector, source/impact review columns, and functional entry and repair feedback animations. Motion uses transform/opacity, lasts 120–240 ms, and honors the operating system's reduced-motion preference. Frequent navigation and app selection are instant. Repair history renders in the same newest-first order as the controller.
